# QEOS AI Context Engine

## Authorization: QEOS-AUTH-0089 Rev.2

## Dynamic Context Switching
The AI Hub dynamically switches context (e.g., Executive, Sales, Inventory, Accounting, CRM, Purchasing) based on the user's current activity. The AI instance NEVER changes; only the active Context changes.

## Capabilities
- Injects current Organization, Branch, Role, Permissions, and Feature Flags.
- Synchronizes with the Localization Engine (Arabic/English).
- Tracks the Current Screen, Current Widget, and Selected Record without fragmenting the unified conversation memory.
