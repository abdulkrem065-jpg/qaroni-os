# QEOS AI Context Engine

## Authorization: QEOS-AUTH-0089

## Purpose
The AI Context Engine aggregates the current state of the application and business to ground the AI's responses.

## Contextual Elements
- **Organization & Branch:** Current operating entity.
- **User Context:** Role and permissions.
- **Application State:** Current screen, widget, selected records.
- **Environment:** Language (Arabic/English), Theme, Timezone.
- **Business State:** Current KPIs, financial state, recent activities.
