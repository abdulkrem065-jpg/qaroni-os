# QEOS User Journeys

## Authorization: QEOS-AUTH-0085

## 1. Store Owner
- **Goal:** Monitor business health, manage high-level configuration.
- **Journey:** Logs in -> Lands on executive Dashboard -> Reviews daily sales, cash flow, and AI insights -> Checks low stock alerts -> Approves pending large purchase orders -> Reviews staff performance reports.

## 2. Branch Manager
- **Goal:** Ensure smooth daily operations for a specific location.
- **Journey:** Logs in -> Reviews branch-specific Dashboard -> Opens daily shift/register -> Checks attendance -> Handles customer escalations or overrides at POS -> Generates end-of-day branch reports.

## 3. Cashier
- **Goal:** Process transactions quickly and accurately.
- **Journey:** Logs in -> Opens cash register -> Scans items / selects from quick grid -> Applies discounts (if permitted) -> Collects payment (Cash/Card/Credit) -> Prints/Emails receipt -> Closes register at end of shift.

## 4. Warehouse Employee
- **Goal:** Manage physical stock accurately.
- **Journey:** Logs in -> Views pending Goods Receipts -> Receives items from supplier -> Scans barcodes -> Updates stock locations -> Processes stock transfer requests from storefront.

## 5. Accountant
- **Goal:** Maintain financial integrity and compliance.
- **Journey:** Logs in -> Views Accounting Dashboard -> Reconciles daily POS shifts against bank deposits -> Reviews auto-generated journal entries for anomalies -> Processes supplier payments -> Generates monthly Trial Balance and Income Statement.

## 6. Supervisor
- **Goal:** Oversee a specific department (e.g., Sales Floor).
- **Journey:** Logs in -> Monitors live sales activity -> Approves voided transactions -> Performs spot inventory checks.
